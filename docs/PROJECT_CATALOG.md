# Project catalog

Catalog này là nguồn nội dung đã xác minh cho các phase redesign. Không suy diễn thêm metric, demo URL hoặc trạng thái.

## Featured AI/ML

### 1. VietASR Pro

- Repo: https://github.com/CheeseThuong/Vietnamese-asr
- Vietnamese ASR dùng Wav2Vec 2.0, PyTorch và Hugging Face; có Flask demo và FastAPI API.
- Metric: README của repository công bố best WER 13.31%; chỉ dùng metric cùng ngữ cảnh nguồn README này.

### 2. TBD RAG Chatbot

- Repo: https://github.com/CheeseThuong/TBD-RAG-Chatbot
- Local-first hybrid RAG cho tuyển sinh, dùng React/TypeScript/Vite, FastAPI, ChromaDB và Gemini.
- Tính năng đã xác minh: citations, ingest, query rewriting và safe fallback.

### 3. Sentiment Analysis RNN/LSTM/BERT

- Repo: https://github.com/CheeseThuong/sentiment-analysis-rnn-lstm-bert
- So sánh RNN, LSTM và BERT trên IMDB 50K; dùng PyTorch, Hugging Face và Kaggle notebook.

### 4. Fish Pond Water Level Prediction

- Repo: https://github.com/CheeseThuong/Predicting-water-levels-using-Linear-Regression
- Linear, Ridge và Polynomial Regression với scikit-learn và Streamlit.
- Dataset mô phỏng gồm 800 samples.

### 5. BotChat Support Students TBD

- Repo: https://github.com/CheeseThuong/BotChat-Support-Students-TBD
- Retrieval chatbot dùng TF-IDF, cosine similarity, NLTK, pandas và Tkinter.
- Không mô tả project này là LLM hoặc RAG.
